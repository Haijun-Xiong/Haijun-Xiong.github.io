## Google Scholar statistics

The homepage loads the citation count and h-index from
`data/scholar.json`. The `Update Google Scholar stats` GitHub Actions
workflow refreshes that file and the fallback values in `index.html`
every Monday and Thursday.

To refresh it immediately after publishing these changes, open the
repository's **Actions** tab, select **Update Google Scholar stats**, and
choose **Run workflow**.
